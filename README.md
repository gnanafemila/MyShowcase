# MyShowcase 🏆

MyShowcase is a personal portfolio management web application developed using React, Node.js, Express and MySQL. It provides users with a single platform to manage and showcase their projects and personal achievements.

The main goal of this project is to make it easier for individuals to organize their work and share their accomplishments through one portfolio.

## 🚀 Features

- User Registration
- User Login
- Profile Management
- Add and View Projects
- Delete Projects
- Personal Showcase
- Centralized portfolio management

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| React.js | Frontend development |
| Node.js | Backend runtime |
| Express.js | Backend framework |
| MySQL | Database management |
| Axios | API communication |
| CSS | User interface styling |

## ⚙️ How It Works

1. Users register and log in to the application.
2. Users can create and manage their personal profiles.
3. Users can add their projects to their portfolio.
4. Saved projects can be viewed and managed.
5. The showcase provides a central place to present their work.

## 🎯 Project Objective

The objective of MyShowcase is to provide a simple and organized platform where users can maintain their project portfolio and share their work through a single showcase instead of managing multiple links.

## 🔮 Future Enhancements

## 💻 Installation and Setup

### Prerequisites

- Node.js
- MySQL
- npm

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/MyShowcase.git
```

### 2. Navigate to the Project Folder

```bash
cd MyShowcase
```

### 3. Install Dependencies

Run `npm install` inside the frontend and backend folders.

### 4. Database Setup

- Open MySQL.
- Create the project database.
- Configure the database connection in the backend.
- Set up the required tables.

### 5. Run the Application

Start the backend and frontend using the scripts configured in their respective `package.json` files.
